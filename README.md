# OKX-Dog Frontend - 极客暗黑专业量化交易终端

OKX-Dog 是一款高品质、金融级暗黑质感的高频量化交易与 AI 智能副驾驶终端前端应用。

## 技术栈与架构

- **核心框架**: React 18 + Vite 5 + TypeScript
- **样式与设计系统**: TailwindCSS + 精心调配的金融暗黑主题（Sleek Dark Theme）
- **图表引擎**: TradingView `lightweight-charts` (多周期 K 线 + EMA 20/50/200 均线组 + 成交量副图 + 持仓/止盈止损/AI关键位叠加)
- **标的检索**: `Ctrl+P` 全景资产检索器（TradFi 黄金/美股代币/RWA/加密龙头/持仓联动）
- **状态管理**: Zustand 分片响应式架构 (`useAppStore`)
- **通讯链路**: WebSocket 毫秒级全双工长连接 + SSE (Server-Sent Events) AI 思维链流式解析

## 核心功能模块与人机协同双卡片

1. **7x24h 脱机常驻操盘看板 (`AutoPilotCard`)**:
   - 守护运行状态指示、多标的轮巡池（增删监控标的）；
   - 组合最大并发持仓数控制与动态移动保本 (Breakeven Locked) 状态；
   - 状态机与后端权威状态 100% 双向对齐（杜绝本地 `isRunning` 虚假状态导致的一键启动阻断）；
   - 后端自主巡检事件流实时展示与时序收益率走势。
2. **AI 智能副驾驶卡片 (`AICopilotCard`)**:
   - 专职于交易员主观深度多周期研判；
   - 思维链 `<think>` 打字机渐显解析；
   - ⚡ **一键直接开仓 (市价直通)** / **⚙️ 参数微调采纳**。
3. **全景资产检索器 (`SymbolSelectorModal` / `Ctrl+P`)**:
   - 实盘/模拟持仓置顶联动、TradFi 专区、自选星标收藏与自定义 OKX 合约快速添加。
4. **交易调度与持仓委托面板 (`PositionList` / `OrderForm`)**:
   - `活跃持仓`: 标的、方向、开仓均价、标记价、UPL 浮盈、预估强平价、止盈止损调整、市价全平；
   - `当前挂单/委托`: 委托单号、价格、数量、成交进度、一键撤单；
   - `历史成交记录`: 平仓明细、已实现盈亏、收益率与平仓归因。
5. **极简通俗 AI 决策员工看板 (`AgentTeamModal` / 「👥 AI 员工」)**:
   - 拟人化展示 6 大量化员工角色（冲锋多头、铁血风控、全球情报、链上巨鲸、盘口狙击、量化仲裁）；
   - 实时展示各角色决策话语权进度条 (%)、员工等级 (Lv.1~Lv.10)、带单战绩与排雷次数；
   - 动态展示今日自主学到的实战避坑秘籍；
   - 决策话语权仅由实盘真实交易结算驱动（隔离模拟数据），支持一键回滚出厂基准与重置出厂设置。

6. **硬风控熔断中枢与 Panic Button**:
   - 顶部 Panic Button 两阶段紧急全撤全平；
   - AES-256 安全密盒管理。
7. **全景量化运维监控看板 (`OpsMetricsModal` / 顶部 Header 状态胶囊)**:
   - 顶部导航栏直观内嵌三大高频量化运维胶囊（WS 延迟毫秒指示、Maker 挂单占比、对账中枢自愈状态）；
   - 点击唤起专业暗黑运维看板，实时监控 WebSocket 心跳与 REST 往返时延 (RTT)；
   - 订单执行质量剖析：Maker 挂单占比统计与手续费摩擦节省比率（拒绝做交易所手续费打工仔）；
   - 远端持仓对账中枢监视器：实时展示与 OKX 事实源同步时间与自愈幽灵持仓次数，支持一键发起强制全量对账；
   - 列式数据湖监控：时序 K 线总量、历史真实资金费率与全网持仓量 (OI) 覆盖状态一览无余。

## 快速启动与构建

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 生产打包验证 (TypeScript 校验)
npm run build
```
